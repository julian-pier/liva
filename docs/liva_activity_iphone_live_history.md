# Historische iPhone-Live-Erfassung

RemoteXPC-/Syslog-basiertes iPhone-Live-Tracking wurde experimentell validiert,
aber wegen unzureichender Zuverlässigkeit für den Produktionsbetrieb entfernt.
Es wurde durch den aggregierten täglichen iOS-Import aus StayFree ersetzt.

Der geschützte RemotePairing-Record wird von LIVA nicht mehr verwendet und
bleibt bis zu einer separat bestätigten manuellen Entfernung erhalten.
